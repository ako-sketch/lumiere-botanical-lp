# LUMIÈRE BOTANICAL LP(ポートフォリオ用)

洋梨とジャスミンのヘアケアセットを題材にした、架空商品のランディングページです。
元のデザイン画像をもとに、HTML/CSS/JSのみで作成しています(ビルド不要)。

## ページ構成

| ファイル | 内容 |
| --- | --- |
| `index.html` | LP本体 |
| `entry.html` | キャンペーン応募フォーム(入力チェックのみ。データは送信・保存しない) |
| `thanks.html` | 応募完了画面 |
| `shop.html` | 「今すぐ購入する」の遷移先(外部ショップへ移動する想定のデモ画面) |

- スマホ幅(最大480px)のデザイン。PCでは画面の中央にスマホ幅で表示します。
- 写真は元のデザイン画像から切り出したものを `images/` に置いています。文字はHTMLで組み直しています。
- 架空の商品・キャンペーンです。ページ下部とフォーム・中継画面にその旨を明記しています。

## ローカルで確認する

```sh
python3 -m http.server 8123
# http://localhost:8123/ を開く
```

## 公開(Vercel)

公開先はVercelです。デプロイ方式は、実際に決めたらここに追記してください。

- 元デザインの画像は、このフォルダの外(`~/dev/ako-lp-private/`)に置いています。
  このフォルダには含めないため、デプロイや git の対象にはなりません。
- 「公式アカウントはこちら」ボタンは、Instagramへ移動せず「これは架空のサイトです（デモ）」を表示します。

- 手動デプロイ: `vercel` / `vercel --prod`
- GitHub連携: pushすると自動でデプロイ
